# LLM Chat 工作台

一个**零第三方依赖**的桌面工作台：把本地 llama.cpp 对话、sd.cpp 生图 / 生视频、以及云端
OpenAI 兼容 API 收进同一个窗口，只用 Python 标准库 + Tkinter 写成，不需要 `pip install`
任何东西，也不依赖任何 Web 服务或后台守护进程。

> 本仓库**只包含工作台代码**。推理引擎、模型权重、云端密钥都不在仓库里，
> 需要按下面的《你需要自己准备的东西》各自获取。

---

## 它能做什么

| 能力 | 说明 |
|---|---|
| 本地对话 | 调用 llama.cpp 的 `llama-server`，图形界面里选模型、启动/停止服务、看思考链与 token 用量；按模型分别记忆上下文长度与 GPU 层数 |
| 发图片给模型 | 支持看图的模型（本地＝配了视觉投影器 `mmproj`，云端＝你声明过或验证过）可以直接收图 |
| 发文本文件 | `.txt` / `.md` / 代码 / **.docx** 作为附件，按模型上下文预算自动折行截取；PDF 与老版 `.doc` 会明确拒绝并提示另存 |
| 生图 | 本地走 sd.cpp 引擎，文生图 + 参考图编辑，产物保存成文件并显示在对话流里；会按权重文件自动认模型族（Qwen-Image / FLUX / SD3 / SDXL / SD1.5…）决定要哪些配套文件与参数，认错了可在 设置 → 生图 手动指定。云端走服务商接口，也可以挂参考图改图 |
| 生视频 | 本地走 sd.cpp 的视频链路（MiniMax-H3 三件套；Wan 2.2 / LTX 等家族按同一套适配层接），文生视频 / 图生视频，输出 webm / avi / webp；云端走异步任务，**只接文生**（首帧请用本地） |
| 云端对话 | 内置 DeepSeek、阿里云 Token Plan、阿里云百炼（按量）、MiniMax、智谱GLM、Kimi、腾讯云混元（按量）、华为云 MaaS（按量），也可自填任意 OpenAI 兼容端点；密钥单独存放，不进配置文件 |
| 对话记录 | 文本模型的对话自动保存成 JSON 文件（`chat_logs/`），含图片的轮次只记文字。当前版本只保存，还不能在界面里读回 |
| 本机 API | 可把"当前选中的本地文本模型"暴露成一个 OpenAI 兼容的本机端点，给 agent 或其他软件直接调用；API Key 在这一页生成与复制。**要有本地文本模型才开得起**（只转发本地模型），没有时这一项默认关闭 |

## 环境要求

- **Windows**（按 Windows 设计与验证；停止服务、显存探测等少量调用用了 `taskkill` / `nvidia-smi`，跨平台需自行适配）
- **Python 3.9+**，且带 Tkinter（python.org 的 Windows 安装包默认自带；部分精简版 Python 需要单独装 `tkinter`）
- 显存 / 内存 / 磁盘需求取决于你选的模型与档位

## 快速开始

1. **准备推理引擎**（本仓库不含，界面里也能直接开下载页：**设置 → 本地模型 → 获取引擎**）
   - 对话引擎：**[llama.cpp](https://github.com/ggml-org/llama.cpp)** →
     [Releases](https://github.com/ggml-org/llama.cpp/releases) 下载对应平台的预编译包
     （CUDA 版还要把 `cudart` 包的 dll 放到同一目录），或者直接跑仓库里的脚本：
     ```bash
     bash tools/deploy_llamacpp.sh ./llama-engine
     ```
     脚本支持 `BUILD` / `FLAVOR` / `MIRROR` 环境变量换构建号、换 CPU/CUDA 版本、走 GitHub 加速镜像。
   - 生图 / 生视频引擎：**[stable-diffusion.cpp](https://github.com/leejet/stable-diffusion.cpp)** →
     [Releases](https://github.com/leejet/stable-diffusion.cpp/releases) 取 `sd-cli`（Windows 为 `sd-cli.exe`）
     与同级 dll。**只想聊天可以不下这一个。**
   - 打开工作台：对话引擎在 **设置 → 本地模型 → 服务参数** 指路，生图引擎在 **设置 → 本地模型 → 生图** 指路。
2. **放模型**（本仓库不含）
   - 默认约定：把 `.gguf` 放进**程序目录下的 `models/`**；换目录在 **设置 → 本地模型 → 服务参数** 的
     `models_dir` 里改（生图 / 生视频权重各有自己的目录字段，分别在 **设置 → 本地模型 → 生图 / 生视频**）。
   - 工作台会扫描这些目录并把模型分进「文本模型 / 生图模型 / 生视频模型」三组菜单；
     **设置 → 本地模型 → 模型文件管理** 用来补全每个模型的 GPU 层数、上下文与 `mmproj` 配对记录。
3. **启动**
   ```bash
   python llama_gui.py        # 带控制台，第一次跑推荐，报错直接看得见
   pythonw llama_gui.py       # 无控制台窗口
   ```
   在左上角选模型 → 点「启动服务」→ 顶栏状态变成 **● 运行中** 就能对话。云端模型不需要启动服务，选上即用。

| 用途 | 从哪拿 | 拿什么 | 放哪 |

| 对话模型 | HuggingFace 等模型站上的 GGUF（Qwen、DeepSeek、GLM、Gemma…） | `*.gguf` | `models/` 或自定模型目录 |
| 让模型能看图 | 同上模型页面 | `mmproj-*.gguf` 视觉投影器 | 与主模型同目录，界面会自动配对并标注 |
| 生图引擎 | [leejet/stable-diffusion.cpp](https://github.com/leejet/stable-diffusion.cpp) 的 [Releases](https://github.com/leejet/stable-diffusion.cpp/releases) | `sd-cli`（Windows 为 `sd-cli.exe`）+ dll | 单独目录，**设置 → 本地模型 → 生图** 指路；同样可以在 **设置 → 本地模型 → 获取引擎** 直接打开下载页 |
| 生图权重 | Qwen-Image / SD1.5 / SDXL / Flux 等的 GGUF 或 safetensors | 模型文件 | 生图模型目录 |
| 生视频 | MiniMax-H3 视频链路的**三件套**：扩散主体 GGUF、文本编码器、视频 VAE | 三个文件都要，**VAE 最容易漏** | 生视频模型目录，**设置 → 本地模型 → 生视频** 指路 |
| 云端对话 | 各服务商控制台（DeepSeek、阿里云 Token Plan / 百炼、MiniMax、智谱、Kimi、腾讯云混元、华为云 MaaS） | API Key | **设置 → 云端模型 → 服务商与密钥** 的密钥按钮（存进 `secrets.json`，不入库） |
| 云端生图 / 生视频 | 服务商**原生接口**（不是 OpenAI 兼容格式）：生图走同步端点，生视频走异步任务 | 同上，另外该模型要在服务商侧**已开通** | 档位与存放目录在 **设置 → 云端模型 → 生图 / 生视频** |

## 装好后打不开、或者用不了：先跑一次诊断

程序内置了一键诊断，**只读本机信息**：不联网、不启动推理引擎、不碰显卡。
入口是 **设置 → 关于与诊断 →「诊断」→ 一键诊断**。它会逐项回答：

| 它查什么 | 对应的症状 |
|---|---|
| 程序所在目录能不能写 | 设置每次都不保存、"我明明配过了又回到默认" |
| `llama-server.exe` 在不在、CUDA 运行库齐不齐 | 点「启动服务」报 `[WinError 2]`，或状态灯卡在"加载中"后掉回"未运行" |
| 显卡型号与显存、内存 | 慢得离谱（模型一层都进不了显卡，全在 CPU 上跑） |
| 模型目录里有没有**能对话的** GGUF | 模型菜单是空的。生图权重与视频组件不算，它们不会进聊天列表 |
| 8080 / 8081 端口有没有被别的程序占 | 服务永远不就绪、agent 接不进来 |
| 配置文件是不是被写坏了一半 | 设置"全没了"（与"从没配过"是两回事，它会分开报） |
| 程序放在 OneDrive / 网络盘 / U 盘上 | 加载特别慢、偶发写不进 |
| 界面看着比预期大一圈、还有点糊 | 高分屏没开 DPI 感知 → **设置 → 关于与诊断 → 高分屏清晰度**，勾上后重开程序 |
| 文件带不带 Windows 的"来自网络"标记 | 双击被 SmartScreen 拦、提示"已保护你的电脑" |

三条常见处置：

- **双击 `llm-chat.exe` 没反应**：程序把启动阶段的异常写进自己所在目录的
  `llm-chat-error.log`。先看这个文件；如果没有它，多半是杀毒软件或 Windows 把刚下载的
  文件拦下来了 —— 右键 exe → 属性 → 解除锁定，或允许通过。
- **exe 请放在可写的普通文件夹里**（例如 `D:\LLM\`）。放在 `C:\Program Files\` 这类受保护
  目录时，配置和密钥都存不下来，症状就是"每次打开都回到初始状态"。
- 诊断结果右上角有**复制诊断报告**，也可以**保存诊断报告**成 `diagnose.txt` 贴给别人求助。

第一次打开还会自动放一遍**遮罩引导**（6 步，指出状态灯、模型菜单、输入框、📎 附件、
启动服务、设置的位置；被指着的控件可以直接点，右上角随时跳过）。想再看一遍：
**设置 → 关于与诊断 → 新手引导**。

## 界面与常用操作

- **顶栏**：模型选择菜单（本地与云端混排，云端条目带「（云）」后缀）、状态灯、启动/停止服务。
  某家云模型太多时按名字前缀收成可展开的组，凑不成一组的进「其他」。
- **对话区**：`Enter` 发送、`Shift+Enter` 换行；生图中可随时「停止生成」；每轮结束显示 token 用量
  （思考模型会单列"其中思考 N"）。
- **📎 附件**：图片或文本文件。被拦下时提示会说明原因，并允许你"仍按支持图片处理"一次。
- **设置 → 本地模型 → 模型文件管理 → 管理本地模型…**：一屏看全三组本地模型，生图 / 生视频模型下面
  列出它实际用到的配套文件（VAE / 文本编码器 / CLIP / T5…）。不想在顶部菜单里看到的条目
  可以取消勾选（只是不显示，文件不动）；底部有「把配套编码器移出菜单」一键整理。
  缺文件时：**缺了跑不起来的**会在你发提示词时点名，**只影响某个功能的**只在这一页提示。
- **设置：左侧可折叠导航 + 右侧可滚动内容**（鼠标滚轮可用）。分组是「本地模型 / 云端模型」，
  点开叶子即定位到对应区块；字段说明收在字段旁的 **`?`** 里（悬停显示，鼠标可移进气泡接着读），
  只有真正要先看一眼的约束留在外面（如「宽x高」「各家区间不同」「3~15 秒」「不能留空」「重启生效」）。
  区块：本地（获取引擎 / 生成参数 / 服务参数 / 生图 / 生视频）· 模型文件管理 ·
  云端（服务商与密钥 / 文本模型 / 生图·生视频）· API 连接 · 关于与诊断。
  底部「保存」是统一入口——当前页任一区块保存不通过时不会关窗。
- **云端选模型**：填好地址与密钥 → 测试连接 → 点「选择模型…」在弹窗里勾选要收进菜单的模型
  （清单来自接口的 `/models`，拉过一次就缓存，只有点「刷新清单」才重新请求；
  也可以手填模型名让服务端验证）。**生图 / 生视频的模型名常常不在 `/models` 清单里**
  （清单只列对话模型），所以那里另有一个「直接加入」：按名字收进来，能力在那一行右侧改。
  同一弹窗里能给每个模型声明「图片输入：自动判断 / 支持 / 不支持」，
  **改动即时生效**，不必点确定。

## 配置文件放在哪

| 文件 | 内容 | 是否入库 |
|---|---|---|
| `gui_config.json` | 运行期配置（含你本机的路径） | **否**（`.gitignore` 已排除） |
| `secrets.json` | 只存云端 API Key | **否**（同上，任何备份也应排除） |
| 生成产物 | 本地：`<sd.cpp 目录>/output/`（图）与 `video/`（视频）；云端：`<程序目录>/cloud_out/images` 与 `videos`。都可在设置里改。生视频与云端任务另写一份**同名 `.log`**，失败时界面直接给出路径 | 否 |
| `cloud_jobs.json` | 云端异步任务台账（task_id 与提交时间），断电或关窗后靠它「取回」 | **否**（换机器还原时产物地址早过期了，带着只会误导） |
| `chat_logs/` | 文本模型的对话记录，每轮自动写一份 JSON（`chat_log_save` 关掉、`chat_log_dir` 改目录） | **否**（纯本机内容，里面是你聊过的话） |

首次运行会自动生成默认配置；换机器时重装模型、重填路径即可，没有需要迁移的隐藏状态。

## 能力边界（先看这段，省得踩坑）

- **云端生视频只支持文字生成**，要给首帧请改用本地的生视频模型。**云端生图可以挂参考图**：
  阿里云是在你给的这张图上改，MiniMax 把这张图当主体 / 角色参考（出的是一张新画面）。
  没有这个功能的服务商，在点 📎 时就会说明，图片不会被丢。
- **云端生图 / 生视频走的是服务商自己的接口，不是 OpenAI 兼容格式**。认得这四家：阿里云、
  MiniMax、智谱GLM、华为云 MaaS。域名认不出来的（自建网关、代理）可以在
  **设置 → 云端模型 → 服务商与密钥** 里手动选协议或填地址。官方没有这类接口的不接：
  Kimi 只有对话与看图输入，腾讯混元的生图 / 生视频不在同一套鉴权里 —— 选中这类模型会在
  发送前说明原因，改用本地那一组即可。
- **各家接口按官方文档对接，能不能出片还取决于你的账号是否开通了该模型**。第一次用请先挑
  最小档位试一张 —— 这些调用会产生实际费用。
- **云端生视频是先建单再交付**：排队中可以取消，开始运行后就取消不了、照常计费。
  所以发送前会弹一次费用确认，运行中点「停止生成」只是不再等它。
- **云端产物地址只活 24 小时**，因此拿到就立刻下载到本地；没来得及下载的记在
  `cloud_jobs.json`，重启后对话开头给「取回」按钮，超过 24 小时会直说取不回来。
- **云端模型能不能看图，接口不会告诉你**，需要在「选择模型」里自己声明，
  或点「验证图片输入」试一次。
- **本地模型没配 `mmproj` 就收不了图**，这是引擎限制，不是界面问题。
- **对话与生图 / 生视频都要吃显存**，同时占用会先弹确认；取消即放弃，不会偷偷排队。
- **附件会留在对话历史里每一轮重发**。云端预算因此有上限（可在设置里按服务商声明真实上下文窗口），
  不是"能塞多塞"——超长上下文的成本是按每一轮计的。
- 所有云端请求带一个通用客户端标识（User-Agent），用于避免部分平台把自建客户端识别成异常流量。

## 目录结构

```
llama_gui.py                 启动入口（只有十几行）
llm_console/
  core/                      配置、模型扫描、GGUF 元数据、参数计算、看图能力判定、
                             本地模型清单与配套文件关系、文本附件预算、服务商注册表、
                             密钥存取、对话记录保存、引擎进程管理、
                             云端任务台账（cloud_jobs.json）
  connection/                本地 SSE 流、云端 OpenAI 兼容文本流、云端原生媒体接口
                             （生图同步 / 生视频异步任务）、本机 API 代理
  ui/                        主窗口 + 聊天 / 生图 / 生视频 / 模型管理 / 服务 / 设置 六个 Mixin
                             （widgets.py：左侧导航、滚动区、"?" 悬停提示等共用小部件）
tools/deploy_llamacpp.sh     取 llama.cpp 引擎的脚本（参数化）
```

分层规矩：`core/` 与 `connection/` **不 import tkinter**，所有界面代码只在 `ui/`。
渲染层只吃统一的事件流，本地与云端共用同一套解析。

## 打包成 exe（可选）

不打包也能用（`python llama_gui.py` 就是完整程序）。想要一个双击即开的 `llm-chat.exe`：

```bash
python -m pip install "pyinstaller==6.21.0"
python -m PyInstaller --noconfirm --clean --onefile --windowed --name llm-chat \
  --distpath dist --workpath build/work --specpath build llama_gui.py
```

- 产物是**界面程序**（约 12MB），推理引擎与模型权重仍然要按上面的表格自己准备；
  推荐把 `llm-chat.exe` 直接放进 `llama-server.exe` 所在的那一层目录 —— 配置默认按
  "与 exe 同目录"来找引擎和 `models/`，`gui_config.json` / `secrets.json` 也生成在那儿。
- 自检：`llm-chat.exe --selfcheck`（退出码 0 = 打包路径与内置服务商都正常）、`--version`。
- exe **未做代码签名**，第一次运行 SmartScreen 可能拦一下：「更多信息」→「仍要运行」。
